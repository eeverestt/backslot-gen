# Backslot Mod: JSON Generator (CLI)

Automatic JSON generation for Medecoole's [Backslot Mod](https://modrinth.com/mod/backslot-mod)

## Authors

- [@eeverest](https://github.com/eeverest)
- [@medecoole](https://github.com/medecoole)


## Installation

Build the project easily using `cargo`
```bash
  git clone 
  cd backslot-gen
  cargo build
```

Then, add to root, to make it runnable from CLI.
